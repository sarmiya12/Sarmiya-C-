# Sarmiya C — Static Portfolio

A responsive portfolio website made using only HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — styling and responsive layout
- `script.js` — mobile menu, current year, and copy-email interaction
- `sky-reference.jpg` — the uploaded sky image used as the colour/background reference

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

No framework, package manager, or build step is required. The font import uses Google Fonts; system fallback fonts work without an internet connection.

## Personalize
Update the contact details, dates, education, and experience in `index.html` if anything changes.
